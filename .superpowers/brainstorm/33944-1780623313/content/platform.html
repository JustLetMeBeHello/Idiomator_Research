A — Extend ResearchOS (new tab)

Add a ProductivityOS tab to the existing desktop app. Python reads/writes Obsidian vault directly. One app, everything in one place. No deployment needed.

Pros

  • Already built & running
  • Direct Obsidian file access
  • One window for everything

Cons

  • Locked to desktop
  • Plain HTML/CSS (no shadcn)
  • Charts need Chart.js, not React

B — New Next.js + shadcn app (local + Vercel)

Standalone web app. Local Next.js dev server reads/writes Obsidian files via API routes. shadcn charts for visuals. Deploy to Vercel for access from phone/anywhere.

Pros

  • Full shadcn component library
  • Rich charts (Recharts/Tremor)
  • Access from any device

Cons

  • Separate from ResearchOS
  • Vercel can't read local files (need local API)
  • More setup

C — Obsidian-native (Bases + Canvas + Templates)

Everything lives in your vault. Bases tables for habit data, Canvas boards for visual timelines, templates for daily bullet journal. Zero extra apps.

Pros

  • Already where your data is
  • No sync needed — IS Obsidian
  • Works offline, no servers

Cons

  • Limited chart types
  • No automated compound tracking
  • Can't integrate w/ ResearchOS easily
