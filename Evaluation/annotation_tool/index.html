ANNOTATION GUIDE

① Idiomaticity Label

Is the idiom in this sentence used figuratively (idiomatic) or literally (literal)? The label is pre-filled — your job is to confirm or correct it.

IDIOMATIC  "She kicked the bucket last night." → means she died (figurative).
LITERAL  "He kicked the bucket across the yard." → physically kicked a bucket.

If you disagree with the pre-filled label, click the other button. Your choice overrides it.

② Span Annotation

The highlighted words in the sentence should mark exactly the idiom expression — no more, no fewer words. Mark Correct if the highlight is accurate, Wrong if it is off.

✓ CORRECT  "She [kicked the bucket] last night." — span covers the full idiom.
✗ WRONG  "She [kicked the] bucket last night." — span is too short.
→ Type the correct span text in the box that appears.

When marking wrong, write the exact phrase that should be highlighted (copy it from the sentence).

③ Sense Context

This question only appears when a sense definition is shown (the purple box). The dataset has multiple senses per idiom; you must check whether the sentence is using the specific sense described.

✓ Correct sense — The sentence clearly uses the idiom in the meaning described in the definition.
△ Uncertain — The sentence is ambiguous; you can't tell which sense is intended. Add a note if helpful.
✗ Wrong sense — The sentence uses the idiom, but in a different sense than the definition. Add a note explaining what sense you think it is.

General tips

• Go with your first instinct — don't overthink. If you're uncertain after 30 seconds, mark it Uncertain and add a note.

• You can go back — click ← Prev to revisit and change any previous answer.

• Your progress is saved automatically — if you close the browser, reopen it and your name will be pre-filled. Click Continue and pick the same language to resume.

• Notes field — use the optional notes box at the bottom of each card for anything that doesn't fit the structured options.

• Export when done — on the completion screen, click Export results.jsonl and send that file to the researcher.
